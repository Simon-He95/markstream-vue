SolidJS streaming Markdown playground

Try markstream-solid, a native SolidJS 1.9 and SolidStart Markdown renderer for AI chat, SSE and WebSocket streams.

Explore incomplete Markdown, streaming code blocks, syntax highlighting, KaTeX math, Mermaid diagrams, and long conversation history restoration.

Install with pnpm add markstream-solid solid-js@^1.9 and import markstream-solid/index.css.
