# 对比

将 `markstream-vue` 与常用选项进行对比：

- 与纯静态渲染相比，`markstream-vue` 支持流式渲染与逐步更新，适用于实时编辑场景。
- 与大型 Markdown-to-HTML 框架相比，目标是更小的内存占用与更快的首次渲染（以避免大量 DOM 操作）。

（更多细节参见英文版 `/guide/compared` 或中文版 `/zh/guide/compared`）
