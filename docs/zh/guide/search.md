# 搜索

本站点启用了 VitePress 的本地搜索（Local Search）。

## 如何使用

- 点击右上角的搜索框，输入关键词即可搜索当前语言下的文档内容
- 桌面端快捷键：`⌘ K`（macOS）/ `Ctrl K`（Windows / Linux）打开搜索

## 小贴士

- 搜不到时先确认语言是否正确（中英文内容分别在 `/` 与 `/zh/`）
- 搜索对组件名/函数名很友好，建议直接搜 `MarkdownRender`、`enableMermaid`、`enableKatex` 等关键字
