# markstream-octane playground

Try the [online Octane playground](https://markstream-octane.pages.dev/).

This is the native Octane counterpart of `playground-react19`. It keeps the
same streaming Markdown conversation, settings, themes, custom `thinking`
node, workers, `/test` regression lab, and shareable test-page behavior while
rendering through `octane` and `markstream-octane`.

```bash
pnpm play:octane
```

The playground runs at <http://localhost:4176>.
